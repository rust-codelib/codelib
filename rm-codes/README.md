# rm-codes — двоичные коды Рида–Маллера

Библиотека для двоичных кодов `RM(r, m)`: кодер по коэффициентам булева
полинома, мажоритарный декодер Рида, конфигуратор, наблюдатель и подсчёт
битовых ошибок.

Rust 1.81+ · `std` · `unsafe` запрещён.

## Быстрый старт

```rust
use rm_codes::{Bit, RmConfig, RmConfigurator, RmDecodeStatus};

fn main() -> Result<(), rm_codes::RmError> {
    let config = RmConfig::new(1, 4)?; // RM(1, 4), [16, 5, 8]
    let code = RmConfigurator::build(config);

    let message = vec![
        Bit::One, Bit::Zero, Bit::Zero, Bit::One, Bit::One,
    ];
    let word = code.encode(&message)?;
    assert_eq!(word.len(), 16);

    // Вносим три ошибки — код RM(1, 4) исправляет до трёх.
    let mut received = word.clone();
    received[13] = received[13].flip();
    received[14] = received[14].flip();
    received[15] = received[15].flip();

    let result = code.decode(&received, None)?;
    assert_eq!(result.status(), RmDecodeStatus::Corrected);
    assert_eq!(result.message(), message.as_slice());
    assert_eq!(result.word(), word.as_slice());
    assert!(result.corrected_positions().len() <= 3);

    Ok(())
}
```

## Параметры кода

| Параметр | Значение |
|---|---|
| Обозначение | `RM(r, m)` |
| Длина | `n = 2^m`, `1 <= m <= 12` |
| Размерность | `k = Σ_{i=0}^{r} C(m, i)` |
| Расстояние | `d = 2^(m-r)` |
| Исправляется | `t = (d - 1) / 2` ошибок |
| Обнаруживается | `d - 1` ошибок |

Ограничение `m <= 12` даёт `n <= 4096` и согласовано с пределом оси матрицы
в остальном workspace.

## Порядок сообщения

Сообщение — коэффициенты булева полинома от `m` переменных. Порядок:

```text
x0, x1, ..., xm,
x12, x13, ..., x(m-1)m,
x123, ...
```

Внутри одной степени коэффициенты идут лексикографически по номерам
переменных. Коэффициент `x_i` соответствует биту `(m - i)` номера позиции.

Кодирование **несистематическое**: биты сообщения не находятся в фиксированных
позициях кодового слова. Восстановить коэффициенты из допустимого слова можно
через `extract_message` или через результат декодирования.

## Декодирование

Используется мажоритарный алгоритм Рида:

1. коэффициенты обрабатываются по убыванию степени;
2. для каждого коэффициента считаются голоса по смежным классам;
3. решение принимается строгим большинством;
4. найденный моном вычитается из рабочего слова;
5. свободный член определяется большинством по оставшимся битам.

Статусы результата:

- `Valid` — вход уже был кодовым словом;
- `Corrected` — все голосования дали строгое большинство, слово изменено;
- `Ambiguous` — была хотя бы одна ничья; возвращён детерминированный
  кандидат, но он не гарантирован.

`Corrected` не означает, что исходное переданное слово точно восстановлено:
при числе ошибок больше `t` возможно ошибочное исправление. Для честной
проверки используйте `count_bit_errors` и эталон.

## Ограничения первой версии

- только жёсткие решения, без LLR;
- без входных стираний и подсказок о позициях ошибок;
- без байтовой упаковки;
- без систематического кодера;
- без ML/Адамар-декодера для `RM(1, m)`;
- `r = m` разрешён, но код не имеет избыточности и ничего не исправляет.
