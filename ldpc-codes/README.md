# ldpc-codes

Библиотечный crate для двоичных LDPC-кодов. Сейчас реализованы тип бита, преобразование битов в `Vector<Gf2>` и обратно, разреженная проверочная матрица `H`, её смежности, синдром и проверка допустимости слова. Систематический кодер, SPA-декодер и преобразование в общий тип многочлена пока не реализованы.

## Текущий API

Все реализованные типы и функции доступны из корня crate `ldpc_codes`.

- `Bit` — `Zero` или `One`. `Bit::try_from(u8)` принимает только 0 и 1, иначе возвращает `LdpcError::InvalidBit`; `u8::from(bit)` выполняет обратное преобразование.
- `Gf2` — псевдоним `gfpm::Gf<2, 1, 1>`, тип элемента поля GF(2).
- `bits_to_vector(&[Bit])` создаёт `gf_linalg::Vector<Gf2>`, сохраняя порядок, пустой ввод и хвостовые нули.
- `vector_to_bits(&Vector<Gf2>)` проверяет каждый элемент и возвращает отдельный `Vec<Bit>`. Если элемент не равен нулю или единице поля, возвращает `LdpcError::InvalidFieldElement` с его индексом и упакованным значением. Проверка также выявляет неканонические элементы, созданные через `Gf::from_coeffs` в release-сборке.
- `ParityCheckMatrix::try_from_rows(bits, rows)` принимает число столбцов и список строк со списками индексов единиц. `rows()` и `cols()` возвращают число проверок `m` и битов `n`; `edge_count()` — число единиц `E`.
- `check_bits(check)` возвращает отсортированные индексы битов проверки, а `bit_checks(bit)` — отсортированные индексы проверок для бита. Для существующей пустой смежности возвращается `Some(&[])`, для индекса за границей — `None`.
- `syndrome(word)` возвращает вектор длины `m`: каждая компонента — XOR битов одной строки `H`. `is_codeword(word)` возвращает `true`, если все компоненты синдрома равны нулю.

Матрица хранит обе смежности разреженно и занимает `O(m + n + E)` памяти без плотной таблицы `m × n`. Каждая ось матрицы должна иметь размер `1..=MAX_MATRIX_DIM` (сейчас `MAX_MATRIX_DIM` равен 4096). Пустые строки и одинаковые строки допустимы: пустая проверка всегда даёт нулевую компоненту синдрома, одинаковые проверки остаются отдельными строками. Повтор одного индекса бита внутри одной строки запрещён.

Синдром и проверки принимают слово длины ровно `n`; иначе возвращается `LdpcError::WordLengthMismatch`. Нулевой синдром означает, что слово удовлетворяет заданной матрице `H`, но не гарантирует отсутствие ошибок при передаче: вектор ошибки из ядра `H` не меняет проверок, поэтому ошибочное слово тоже может иметь нулевой синдром.

Ошибки текущего API — `InvalidBit`, `InvalidFieldElement`, `InvalidDimensions`, `BitIndexOutOfBounds`, `DuplicateBitIndex`, `WordLengthMismatch` и `SizeOverflow`. Общий тип `LdpcError` реализует `Debug`, `PartialEq`, `Eq`, `Display` и `std::error::Error`.

Преобразования и вычисление синдрома берут входные данные по ссылке и не меняют их; для результата создаётся отдельная коллекция. На длину вектора и преобразования `bits_to_vector`/`vector_to_bits` не накладываются ограничения 4096 байт для сообщения или 128 КиБ для массива коэффициентов. Последний предел относится к отдельным преобразованиям `gf-linalg` между векторами и массивами коэффициентов.

## Будущие контракты

План описывает `Encoder`, `Decoder`, `LdpcConfigurator`, `DecodeResult` и `DecodeObserver`, но эти имена пока не экспортируются и соответствующая функциональность ещё не реализована. Будущий систематический `Encoder` будет доступен при условии `0 < rank(H) < n`, принимать `k = n - rank(H)` информационных битов, выдавать слово длины `n` и извлекать сообщение из допустимого слова. `LdpcConfigurator` будет собирать кодер и SPA-декодер для одной `H`, выводя размеры и ранг из самой матрицы. `Decoder` будет принимать LLR длины `n` и необязательные позиции стираний. `DecodeResult` предназначен для итогового слова, LLR, синдрома, статуса (`ParitySatisfied` или `IterationLimit`) и счётчиков итераций и изменений; `DecodeObserver` будет получать события начала, завершения итерации и декодирования. Перевод `Vector<Gf2>` в общий тип многочлена и обратно отложен до появления этого типа в проекте.

Запускаемый пример с проверочной матрицей, ожидаемым нулевым и ненулевым синдромом и преобразованиями битов доступен в [`examples/syndrome.rs`](examples/syndrome.rs):

```sh
cargo run -p ldpc-codes --example syndrome
```
